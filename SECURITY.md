# Política de Segurança

## Versões Suportadas

Atualmente, apenas a versão `main` recebe patches de segurança.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reportando Vulnerabilidades

Se você descobrir um problema de segurança crítico neste repositório, **não crie uma issue pública**.
Por favor, envie um e-mail para `security@begbrasil.com.br` detalhando:
- O tipo de vulnerabilidade.
- Passos para reprodução.
- O impacto potencial no sistema.

Responderemos em até 48 horas úteis com as próximas etapas.
